# Samajik Pahal Foundation (SPF)

A responsive React + Vite website starter for Samajik Pahal Foundation, presenting its women-empowerment mission and handcrafted home décor and tableware.

## Preview

- Current Lovable reference: https://samajikpahalfoundation.lovable.app/

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Import this GitHub repository into Vercel.
2. Select **Vite** as the framework if it is not detected automatically.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Deploy, then connect the foundation's approved custom domain when ready.

## Before public launch

- Replace the illustrative product photography with SPF-approved real product images and confirm all descriptions.
- Add the foundation's verified email, phone number, address and social links. The contact CTA needs a valid destination before launch.
- Add the Google Search Console HTML verification tag generated by the foundation's authorised Google account inside the `<head>` of `index.html`, then redeploy. Never guess or publish a verification token.
- Replace `YOUR-SPF-DOMAIN` in `public/sitemap.xml` and `public/robots.txt` with the final canonical HTTPS domain.
- Check all links, mobile responsiveness, accessibility, page speed, and form/contact behaviour.
- Confirm SPF controls the domain, hosting account, repository access, and analytics properties.

## Notes

This is a clean implementation based on the project brief, not a source-code export of the existing Lovable project. The product images are illustrative placeholders from Unsplash and must be replaced or approved by SPF before the website is represented as production-ready. No private credentials or Search Console tokens belong in this repository.
